# InvestaLearning

Website persiapan Ujian Standar Profesi Pasar Modal (WAPERD, WPPE, WMI, dan lainnya), pengganti situs lama investaprima.com.

Laravel 13 · Inertia v3 · React 19 · Tailwind CSS v4 · Wayfinder.

```bash
composer setup   # install, .env, migrate, build
composer dev     # jalankan server + Vite di http://localhost:8000
composer test    # Pint, PHPStan, Pest
```

**Dokumentasi lengkap (kondisi project, keputusan desain, preferensi pemilik, langkah berikutnya): [docs/HANDOFF.md](docs/HANDOFF.md).** Baca itu dulu sebelum mengubah kode.
